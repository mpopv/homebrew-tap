# mpopv/homebrew-tap

Homebrew formulae for [mpopv](https://github.com/mpopv)'s tools.

```sh
brew install mpopv/tap/magsafe
```

| Formula | Description |
| --- | --- |
| [`magsafe`](Formula/magsafe.rb) | Control the light on Apple's MagSafe 3 cable ([source](https://github.com/mpopv/magsafe-cli)) |

The `magsafe-cli` release workflow updates `Formula/magsafe.rb` when a new version is tagged.
